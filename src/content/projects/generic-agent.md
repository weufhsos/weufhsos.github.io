## 项目概览

这是一个围绕通用 Agent 能力进行探索的项目。这里优先记录工作流、工具调用和评估方式，而不是只追求一次成功的演示。

## 记录重点

- 如何把一个模糊目标拆成可验证的步骤。
- 如何让工具调用更容易观察和复盘。
- 如何区分“看起来完成”和“确实得到结果”。

项目细节会随着实验推进持续补充，最新代码以 GitHub 仓库为准。
